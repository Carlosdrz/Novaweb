# Fuente de datos de Nova

Todo lo que pongas en esta carpeta (.md, .txt, .pdf, .csv, .json…) es la fuente
de datos personal de Nova. Antes de responder una pregunta factual, Nova busca
aquí; si no encuentra nada, busca en la web.

Ejemplos de lo que puedes guardar:
- Apuntes, horarios, reglamentos o circulares del colegio
- Datos tuyos: contactos, rutinas, proyectos, documentos importantes
- Manuales, guías o artículos que quieras que Nova domine

Consejos
- Un archivo por tema, con nombres claros (`horario-clases.md`, `contactos.txt`).
- Texto plano o Markdown funciona mejor que PDF escaneado.
- Nova solo lee esta carpeta; nunca la modifica.

La subcarpeta `noticias/` la rellena Nova sola cada día con titulares (un archivo por día,
los últimos 30). No hace falta que la toques.
